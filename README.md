# modu_simsa
두의 심사(담당자용): 채용 심사를 종이 없이 진행하는 단일 HTML 도구입니다. 설치나 서버 없이 브라우저에서 바로 열어 오프라인으로 쓰며, 위원별 평가표 엑셀을 한 번에 취합해 학교·직종별 평균·순위와 합격·예비·과락을 산출합니다. 점수 빈칸, 위원 간 경력 점수 차이, 합격 경계의 동점자는 자동으로 알려 줍니다. 위원은 화면에 직접 서명해 출석부·청렴서약서를 만들고, 집계 결과를 확인한 뒤 최종 서명합니다. 결과 문서는 PDF·엑셀·HTML로 저장되며, 문서마다 SHA-256 확인 코드가 붙어 위·변조 여부를 대조할 수 있습니다. 모든 기록은 사용하는 브라우저에만 저장되고 외부로 전송되지 않습니다.
