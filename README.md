# 모두의 심사 (담당자용)

채용 심사를 종이 없이 진행하기 위한 단일 HTML 도구입니다.
설치나 서버 없이 브라우저에서 파일을 열어 바로 쓸 수 있고, 인터넷 연결 없이도 동작합니다.

## 주요 기능

- 위원별 평가표(엑셀) 여러 개를 한 번에 올려 취합
- 학교·직종별 평균·순위와 합격·예비·과락 판정
- 점수 빈칸, 위원 간 경력 점수 차이, 합격 경계의 동점자 자동 안내
- 위원이 화면에 직접 서명 → 출석부·청렴서약서에 적용
- 위원이 집계 결과를 확인한 뒤 최종 서명
- 결과 문서를 PDF·엑셀·HTML로 저장, 문서마다 SHA-256 위·변조 확인 코드 표시

## 사용 방법

1. 오른쪽 **Releases**에서 최신 버전의 HTML 파일을 내려받습니다.
2. 파일을 더블클릭해 크롬 또는 엣지로 엽니다.
3. 화면 순서대로 진행합니다.
   - **심사 준비**: 심사명·일시·장소, 심사위원, 평가 항목과 배점
   - **위원 서명**: 위원 본인이 서약 확인 후 서명
   - **집계·문서**: 위원별 평가표 올리기 → 결과 확인 → 최종 서명 → 문서 저장

## 데이터와 개인정보

- 모든 기록은 **사용하는 PC의 브라우저에만** 저장되며 외부로 전송되지 않습니다.
- 브라우저 기록을 지우거나 다른 PC로 옮기면 기록이 사라지므로, 심사가 끝나면 **백업 저장**으로 JSON 파일을 보관하세요.
- 공용 PC에서는 업무가 끝난 뒤 **모두 지우기**를 누르세요.
- 실제 심사 자료(백업 JSON, 평가표, 출력 문서)는 이 저장소에 올리지 마세요.

## 코드 구성

HTML 파일 하나에 모든 코드가 들어 있습니다.

- **CSS**: 화면 스타일과 문서 인쇄 스타일
- **ExcelJS**: 엑셀 읽기·쓰기용 내장 라이브러리 (수정하지 않음)
- **앱 스크립트**(파일 맨 끝 `<script>`): 실제 동작 코드
  - 기본값: 평가 항목(`ITEMS_DOC`, `ITEMS_INT`), 청렴서약 문구(`DEF_PLEDGE`), 경력 배점(`DEF_CAREER_MAX`)
  - 집계: `aggregate` (합계·평균·순위·합격 판정)
  - 평가표 읽기: `parseScoreWorkbook`, `applyScorePlans`
  - 문서 만들기: `buildDocs`(인쇄·HTML), `exportXlsx`(엑셀)
  - 서명·위변조 확인: `Pad`, `finalReviewDigest`
  - SHA-256 계산기(hash.js): 내장 라이브러리 (수정하지 않음)

## 수정할 때

1. 원본 파일은 그대로 두고 **사본**을 고칩니다.
2. 줄 번호 대신 **함수 이름으로 검색**(Ctrl+F)해서 찾습니다.
3. **UTF-8**로 저장합니다.
4. 가상 위원·가상 접수번호로 서명 → 평가표 취합 → 최종 서명 → 문서 저장 → 백업·복원까지 점검합니다.
5. 화면 하단 버전을 올리고, Releases에 새 버전으로 올립니다.
